# Architecture decisions

Record decisions that future contributors should not have to rediscover. Use the
name `NNNN-short-title.md`, incrementing the number for each decision.

```markdown
# NNNN: Decision title

- Status: proposed | accepted | superseded
- Date: YYYY-MM-DD

## Context

What prompted the decision and which constraints matter?

## Decision

What was chosen?

## Consequences

What becomes easier, harder, or deliberately unsupported?
```
